# Changelog

All notable changes to Tilda will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.1] - 2025-01-07

### Added
- Added ability to upload multiple files
- Now can create new to-dos from files page
- Repeating to-dos
- Task complete animation

### Fixed
- Adjusted colors on context pages
- General improvements around contexts
- Bug Fixes
- Improved how files show up in tilda chat
- Bugs surrounding tilda chat opening
- Fixed tilda chat stopping after creating task

## [0.1.0] - 2024-12-29

### Added
- Initial release
- Task management with AI conversations powered by Claude
- Contexts for organizing related tasks
- AI learning notes automatically extracted from completed tasks
- Tilda assistant for natural language task management
- Settings for API key and model selection
- Calendar date pickers for task scheduling
- Message editing and retry functionality
- Markdown rendering in chat messages
- Drag and drop task reordering
- Dark mode interface
- Multi-select tasks for bulk operations
- Resizable panel layout with persistence
